# Módulo de Solicitud y Seguimiento de Recolecciones

> Portal de autoservicio para que los clientes de una empresa de paquetería
> soliciten la recolección de un paquete y consulten el estado de su solicitud.

Proyecto **fullstack** (React + Express) desarrollado como prueba técnica.

📄 La documentación completa de instalación, uso y pruebas está más abajo en este
mismo archivo (se completa por fases).

## Estructura del monorepo

```
.
├── backend/     API REST (Node.js + Express) con arquitectura en capas
├── frontend/    SPA (React + Vite)
├── docs/        Diagramas y documentación de apoyo
└── docker-compose.yml
```
